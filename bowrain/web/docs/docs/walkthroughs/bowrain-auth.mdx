# Auth and workspaces from the CLI

With the kapi-bowrain plugin installed, kapi answers everyday questions about
the server: who you are signed in as, where you can push, and whether your
content is ready.

<ThemedVideo
  sources={{
    light: "/video/bowrain-cli/bowrain-cli-auth-and-workspaces-light.webm",
    dark: "/video/bowrain-cli/bowrain-cli-auth-and-workspaces-dark.webm",
  }}
/>

- `kapi auth status` shows the server and account this checkout is connected
  to, which helps when you work with more than one Bowrain server.
- `kapi workspace list` shows every workspace you belong to. A project is
  pushed into one of them, and each keeps its own projects, content memory
  and terms. The browser and the desktop app show the same workspaces in the
  workspace rail.
- `kapi pseudo-translate` writes padded, accented copy (the `qps`
  pseudo-locale) on your machine. It shows layout and truncation problems
  before a reviewer sees the file.
