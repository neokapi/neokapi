àþþ öṽéŕļàý; ţĥé çöñţàîñéŕ'š ŕöüţéŕ öüţ-þŕîöŕîţîžéš ţĥé ĥöšţ ƒîļé-ŕöüţéš ŵĥîļé îţ
îš üþ, àñđ ţĥé šàḿé Ţŕàéƒîķ ƒàļļš ƃàçķ ţö ţĥé ĥöšţ šéŕṽéŕ ŵĥéñ îţ îš ĝöñé. Ţĥé

## ▒ Þŕéŕéǫüîšîţéš ▒

- ▒ Đöçķéŕ (ŵîţĥ Çöḿþöšé ṽ2) àñđ Ĝö. ▒
- ▒ Ţĥé `ķàþî-ƃöŵŕàîñ` þļüĝîñ, ţö đŕîṽé à þŕöĵéçţ ŵîţĥ ţĥé `ķàþî` ÇĻÎ:
  `ƃŕéŵ îñšţàļļ ñéöķàþî/ţàþ/ƃöŵŕàîñ-çļî`. ▒
- ▒ Ƒöŕ ţĥé `*.ƃöŵŕàîñ.ḿýḿàç` (ŢĻŠ) ḿöđéš öñļý, ţĥé öñé-ţîḿé ĥöšţ šéţüþ — ļöçàļ ĐÑŠ
  ƒöŕ `*.ḿýḿàç` àñđ à ļöçàļļý-ţŕüšţéđ çéŕţîƒîçàţé: ▒

  ```bash
  brew install dnsmasq mkcert

sudo mkdir -p /etc/resolver && echo 'nameserver 127.0.0.1' | sudo tee /etc/resolver/mymac
  ```

  ▒ Ţĥé šţàñđàļöñé ḿöđé ñééđš ñöñé öƒ ţĥîš. ▒

## ▒ Đŕîṽîñĝ îţ ŵîţĥ ţĥé `ķàþî` þļüĝîñ ▒

▒ Þöîñţ `--šéŕṽéŕ` àţ ŵĥîçĥéṽéŕ éñţŕý þöîñţ ýöüŕ ḿöđé éẋþöšéš (`ĥţţþ://ļöçàļĥöšţ:8080`
ƒöŕ šţàñđàļöñé, `ĥţţþš://ƃöŵŕàîñ.ḿýḿàç` ƒöŕ ţĥé ŢĻŠ ḿöđéš): ▒

```bash

kapi init --server http://localhost:8080 --anonymous --source-locale en --target-locale fr,de
echo '{"greeting":"Hello"}' > en.json
kapi add en.json
kapi up                         # catch fr,de up on the server: push → catch up → pull
cat fr.json                     # translated catalog
```

▒ `ķàþî îñîţ` šçàƒƒöļđš ţĥé þŕöĵéçţ; ŵĥéñ `--šéŕṽéŕ` îš ĝîṽéñ, ţĥé ƃöŵŕàîñ þļüĝîñ
*çöñţŕîƃüţéš* ţĥé šéŕṽéŕ çöññéçţîöñ — îţ ŵŕîţéš ţĥé `ƃöŵŕàîñ:` ƃļöçķ àñđ šţöŕéš à
çļàîḿ ţöķéñ (`--àñöñýḿöüš`), öŕ çŕéàţéš ţĥé þŕöĵéçţ üñđéŕ ýöüŕ àççöüñţ ŵĥéñ ýöü
àŕé šîĝñéđ îñ (`ķàþî àüţĥ ļöĝîñ`), öŕ àţţàçĥéš ţö àñ éẋîšţîñĝ öñé ŵîţĥ
`--þŕöĵéçţ <îđ>`. Îţ îš îđéḿþöţéñţ: ŕüññîñĝ `ķàþî îñîţ --šéŕṽéŕ …` îñšîđé àñ
éẋîšţîñĝ ļöçàļ ķàþî þŕöĵéçţ çöññéçţš îţ ţö ƃöŵŕàîñ, àñđ ļéàṽéš àñ
àļŕéàđý-çöññéçţéđ þŕöĵéçţ üñţöüçĥéđ. ▒

▒ Ţĥé çüšţöḿ Ķéýçļöàķ ļöĝîñ ţĥéḿé îš öþţîöñàļ — ļöĝîñ ŕéñđéŕš ŵîţĥ ţĥé đéƒàüļţ
ţĥéḿé üñţîļ ýöü ƃüîļđ îţ ŵîţĥ `ḿàķé ķéýçļöàķ-ţĥéḿé`. Ƒöŕ ţĥé ñö-àüţĥ þàţĥ àƃöṽé
