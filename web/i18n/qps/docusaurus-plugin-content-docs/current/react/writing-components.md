# ▒ Ŵŕîţîñĝ ţŕàñšļàţàƃļé çöḿþöñéñţš ▒

▒ Àļḿöšţ éṽéŕýţĥîñĝ ýöü àļŕéàđý ŵŕîţé îš ţŕàñšļàţàƃļé. Ţĥîš þàĝé ŵàļķš ţĥŕöüĝĥ ţĥé ŕüļéš ţĥé þļüĝîñ àþþļîéš, ţĥé ŵàŕñîñĝš îţ ƒîŕéš ŵĥéñ îţ ḿàķéš à ĵüđĝéḿéñţ çàļļ ýöü šĥöüļđ ķñöŵ àƃöüţ, àñđ ţĥé ĥàļƒ-đöžéñ þàţţéŕñš ţĥàţ ƃŕéàķ éẋţŕàçţîöñ šîļéñţļý. ▒

## ▒ Ţĥé šĥöŕţ ṽéŕšîöñ ▒

- ▒ **ĴŠẊ ţéẋţ îñšîđé à ţŕàñšļàţàƃļé éļéḿéñţ** → éẋţŕàçţéđ. ▒
- ▒ **Đîŕéçţ ţéẋţ îñšîđé à çöñţàîñéŕ (`<đîṽ>`, `<šéçţîöñ>`, …)** → éẋţŕàçţéđ (àüţö-þŕöḿöţîöñ, šîļéñţ). ▒
- ▒ **Đîŕéçţ ţéẋţ îñšîđé àñ üñḿàþþéđ Ŕéàçţ çöḿþöñéñţ** → éẋţŕàçţéđ, ŵîţĥ à ŵàŕñîñĝ àñđ à šüĝĝéšţîöñ ţö àđđ à `çöḿþöñéñţḾàþ` éñţŕý. ▒
- ▒ **Îñļîñé éļéḿéñţš ŵîţĥ çĥîļđŕéñ** (`<šţŕöñĝ>ƒöö</šţŕöñĝ>`, `<à ĥŕéƒ="…">ĥéŕé</à>`, `<éḿ>{name}</éḿ>`) → çàþţüŕéđ àš öñé ţŕàñšļàţàƃļé ƃļöçķ; ţĥé îñļîñé éļéḿéñţ ƃéçöḿéš à **þàîŕéđ ḿàŕķéŕ** ŵŕàþþîñĝ îţš îññéŕ çöñţéñţ, šö ţĥé ţŕàñšļàţöŕ šééš ţĥé îññéŕ ŵöŕđš àñđ çàñ ḿöṽé ţĥé ŵŕàþþîñĝ àŕöüñđ. ▒
- ▒ **Žéŕö-çĥîļđŕéñ îñļîñé éļéḿéñţš** (`<ƃŕ/>`, `<Îçöñ/>`, `<Šþîññéŕ/>`, `<Ƃàđĝé/>`) → ƃéçöḿé **šţàñđàļöñé ḿàŕķéŕš** (`{=mN}` ŵîţĥ ñö ḿàţçĥîñĝ çļöšé) îñ ţĥé šüŕŕöüñđîñĝ ţéẋţ. ▒
- ▒ **ĤŢḾĻ àñđ ÀŔÎÀ ţéẋţ àţţŕîƃüţéš** — `àļţ`, `ţîţļé`, `þļàçéĥöļđéŕ`, `àŕîà-ļàƃéļ`, … — öñ **àñý** éļéḿéñţ → éẋţŕàçţéđ. ▒
- ▒ **Ŕéàçţ þŕöþ-ñàḿé çöñṽéñţîöñš** — `ļàƃéļ`, `đéšçŕîþţîöñ`, `ĥéàđîñĝ`, `ĥéļþŢéẋţ`, `ţööļţîþ`, … — öñ **ÞàšçàļÇàšé çöḿþöñéñţš öñļý** → éẋţŕàçţéđ. Öñ à þļàîñ `<đîṽ>` ţĥéšé ñàḿéš àŕé üšüàļļý ĐÖḾ þŕöþš öŕ éñüḿ ķéýš, ñöţ çöþý. ▒
- ▒ **Ţŕàñšļàţàƃļé àţţŕîƃüţéš ŵîţĥ šţŕîñĝ-ļîţéŕàļ ţéŕñàŕîéš** (`ţîţļé={cond ? "A" : "B"}`) → éàçĥ ƃŕàñçĥ éẋţŕàçţéđ àš îţš öŵñ ƃļöçķ. ▒
- ▒ **Ñöñ-ţŕàñšļàţàƃļé éļéḿéñţš** (`<çöđé>`, `<þŕé>`, `<ķƃđ>`, `<ṽàŕ>`, `<šçŕîþţ>`, `<šţýļé>`, `<ţéẋţàŕéà>`) → šķîþþéđ. ▒
- ▒ **Éļéḿéñţš ḿàŕķéđ `ţŕàñšļàţé="ñö"`** (öŕ àñý àñçéšţöŕ) → šķîþþéđ. ▒

## ▒ Ţĥé đéţàîļ ▒

### ▒ Ţŕàñšļàţàƃļé ĴŠẊ ţéẋţ ▒

▒ Ĥéàđîñĝš, þàŕàĝŕàþĥš, ƃüţţöñš, ļàƃéļš, öþţîöñš, `<šþàñ>`, `<šţŕöñĝ>`, `<éḿ>`, `<à>`, `<ƃ>`, `<î>` — ţĥé ŵĥöļé šéţ öƒ éļéḿéñţš ţĥé Ŵ3Ç ĤŢḾĻ5 šþéç çļàššîƒîéš àš þĥŕàšîñĝ öŕ ţŕàñšļàţàƃļé ƃļöçķ çöñţéñţ. ▒

```tsx
<h1>Welcome</h1>                        // ✓ extracted
<p>Ship in every language.</p>          // ✓ extracted
<button>Get started</button>            // ✓ extracted
<label>Email address</label>            // ✓ extracted
<a href="/docs">Read the docs</a>       // ✓ extracted
<option value="fr">French</option>      // ✓ extracted
```

### ▒ Îñļîñé çĥîļđŕéñ — öñé ƃļöçķ, þàîŕéđ ḿàŕķéŕš ▒

▒ Ŵĥéñ àñ éļéḿéñţ ḿîẋéš ţéẋţ ŵîţĥ îñļîñé çĥîļđŕéñ, ţĥé ŵĥöļé ţĥîñĝ ƃéçöḿéš öñé ţŕàñšļàţàƃļé ƃļöçķ. Éàçĥ îñļîñé éļéḿéñţ ŵîţĥ çĥîļđŕéñ ƃéçöḿéš à **þàîŕéđ ḿàŕķéŕ** îñ ţĥé þàŕéñţ'š ţéẋţ — ţĥé ţŕàñšļàţöŕ šééš ţĥé îññéŕ ŵöŕđš àñđ çàñ ḿöṽé ţĥé ŵŕàþþîñĝ àŕöüñđ: ▒

```tsx
<p>
  Click <a href="/docs">here</a> to read the docs.
</p>
```

▒ Ţĥé éẋţŕàçţöŕ šţöŕéš ţĥîš àš `"Çļîçķ {=m0}ĥéŕé{/=m0} ţö ŕéàđ ţĥé đöçš."`. À Ĝéŕḿàñ ţŕàñšļàţîöñ ŕéàđš `"Ķļîçķéñ Šîé {=m0}ĥîéŕ{/=m0}, üḿ đîé Đöķüḿéñţàţîöñ žü ļéšéñ."` — ţĥé ļîñķ ŵŕàþš ţĥé ŕîĝĥţ ŵöŕđ, àñđ à Ƒŕéñçĥ ţŕàñšļàţöŕ çàñ ḿöṽé îţ éļšéŵĥéŕé îñ ţĥé šéñţéñçé éñţîŕéļý. ▒

▒ Îñļîñé éļéḿéñţš ţĥàţ þŕöđüçé þàîŕéđ ḿàŕķéŕš: `<šþàñ>`, `<šţŕöñĝ>`, `<éḿ>`, `<ƃ>`, `<î>`, `<à>`, `<šḿàļļ>`, `<šüƃ>`, `<šüþ>`, `<ţîḿé>`, `<ü>`, `<ŵƃŕ>`, `<đéļ>`, `<îñš>`. (`<çöđé>`, `<ķƃđ>`, `<ṽàŕ>`, `<šàḿþ>` ŕéñđéŕ çöđé-àš-çöđé àñđ àŕé ñöñ-ţŕàñšļàţàƃļé — šéé ƃéļöŵ.) ▒

▒ Ţĥé ŕüļé îš üñîƒöŕḿ: **àñý îñļîñé éļéḿéñţ ŵîţĥ àţ ļéàšţ öñé çĥîļđ → þàîŕéđ þàîŕ**, ŕéĝàŕđļéšš öƒ ŵĥéţĥéŕ ţĥé îññéŕ çöñţéñţ îš ţéẋţ, àñ éẋþŕéššîöñ, àñ îçöñ, öŕ ƒüŕţĥéŕ ñéšţéđ éļéḿéñţš. Éḿþţý îñļîñé éļéḿéñţš ƃéçöḿé **šţàñđàļöñé ḿàŕķéŕš** îñšţéàđ. À ƒéŵ éẋàḿþļéš: ▒

| Source                          | Extracted form                          |
| ------------------------------- | --------------------------------------- |
| `<a>here</a>`                   | `"{=m0}here{/=m0}"`                     |
| `<a><Icon/></a>`                | `"{=m0}{=m1}{/=m0}"`                    |
| `<a>{userName}</a>`             | `"{=m0}{userName}{/=m0}"`               |
| `<strong>{count}</strong>`      | `"{=m0}{count}{/=m0}"`                  |
| `<a>read <em>the</em> docs</a>` | `"{=m0}read {=m1}the{/=m1} docs{/=m0}"` |
| `<Icon/>` (no children)         | `"{=m0}"` (no matching `{/=m0}` close)  |
| `<br/>` (no children)           | `"{=m0}"` (no matching `{/=m0}` close)  |

▒ ĴŠẊ-éļéḿéñţ ţöķéñš àļŵàýš ŕéàđ `{=m<N>}`; ţĥé ŕüñţîḿé ţéļļš šţàñđàļöñé ƒŕöḿ þàîŕéđ ƃý ļööķîñĝ ƒöŕ à ḿàţçĥîñĝ `{/=m<N>}` çļöšé îñ ţĥé šàḿé šçöþé. Ṽàŕîàƃļé ţöķéñš (`{userName}`, `{count}`) çàŕŕý ţĥé ĴŠ îđéñţîƒîéŕ đîŕéçţļý. ▒

### ▒ Éḿþţý îñļîñé éļéḿéñţš àš šţàñđàļöñé ḿàŕķéŕš ▒

▒ Ļöţš öƒ ŕéàļ Ŕéàçţ ÜÎ ļööķš ļîķé `<Ƃüţţöñ><Îçöñ />Öþéñ Ƒîļé...</Ƃüţţöñ>` — àñ îçöñ çöḿþöñéñţ ƒöļļöŵéđ ƃý ţéẋţ. Éḿþţý îñļîñé éļéḿéñţš (žéŕö çĥîļđŕéñ) ƃéçöḿé à šîñĝļé šţàñđàļöñé ḿàŕķéŕ, ļéàṽîñĝ ţĥé šüŕŕöüñđîñĝ ţéẋţ ţö éẋţŕàçţ ñöŕḿàļļý: ▒

```tsx
<Button>
  <FolderOpen size={12} />
  Open File...
</Button>
```

▒ Éẋţŕàçţš àš `"{=m0} Öþéñ Ƒîļé..."` ŵîţĥ `{=m0}` ƃöüñđ ţö ţĥé `<ƑöļđéŕÖþéñ />` éļéḿéñţ (šţàñđàļöñé — ñö ḿàţçĥîñĝ `{/=m0}` çļöšé). Ŵöŕķš ţĥé šàḿé ƒöŕ Ŕàđîẋ îçöñš, ļüçîđé-ŕéàçţ, Ĥéŕöîçöñš, çüšţöḿ `<Šþîññéŕ />` çöḿþöñéñţš — àñýţĥîñĝ ŵîţĥ ñö çĥîļđŕéñ. ▒

▒ Üñḿàþþéđ Ŕéàçţ çöḿþöñéñţš ŵîţĥ çĥîļđŕéñ àŕé šţîļļ ţŕéàţéđ àš ƃļöçķ-ļéṽéļ ƃý đéƒàüļţ (ŵàŕñîñĝ šüĝĝéšţš à `çöḿþöñéñţḾàþ` éñţŕý — šéé "Üñķñöŵñ çöḿþöñéñţš" ƃéļöŵ). Ţĥé ñàŕŕöŵ ŕüļé ƒöŕ _žéŕö-çĥîļđŕéñ_ üñḿàþþéđ çöḿþöñéñţš þŕéṽéñţš ƒàļšé þöšîţîṽéš öñ çüšţöḿ ƃļöçķ-ļéṽéļ çöḿþöñéñţš ļîķé `<Þàñéļ><Ĥéàđîñĝ>…</Ĥéàđîñĝ></Þàñéļ>`. ▒

### ▒ Àüţö-þŕöḿöţéđ çöñţàîñéŕš ▒

▒ Šţŕîçţ Ŵ3Ç šéḿàñţîçš ŵöüļđ šķîþ `<đîṽ>Ĥéļļö</đîṽ>` — đîṽš àŕé çļàššîƒîéđ àš çöñţàîñéŕš, ñöţ ţéẋţ. Îñ ŕéàļ Ŕéàçţ çöđéƃàšéš ţĥàţ'š ŵŕöñĝ: `<đîṽ>Ļàƃéļ</đîṽ>`, `<šéçţîöñ>Îñţŕö çöþý</šéçţîöñ>` àŕé éṽéŕýŵĥéŕé. ▒

▒ ñéöķàþî-î18ñ **àüţö-þŕöḿöţéš** çöñţàîñéŕ éļéḿéñţš ŵĥéñ ţĥéý ĥàṽé: ▒

1. ▒ Àţ ļéàšţ öñé đîŕéçţ ñöñ-ŵĥîţéšþàçé ĴŠẊŢéẋţ çĥîļđ, ÀÑĐ ▒
2. ▒ Öñļý îñļîñé çĥîļđŕéñ (ñö ñéšţéđ ƃļöçķ-ļéṽéļ éļéḿéñţš). ▒

▒ Þŕöḿöţîöñ îš šîļéñţ — `<đîṽ>Ļàƃéļ</đîṽ>` îš ţĥé đöḿîñàñţ îđîöḿ àñđ ŵàŕñîñĝ öñ éṽéŕý öççüŕŕéñçé ŵöüļđ ĵüšţ ƃé ñöîšé. (Üñḿàþþéđ Ŕéàçţ çöḿþöñéñţš šţîļļ ŵàŕñ; šéé ƃéļöŵ.) ▒

▒ Ţö öþţ öüţ: `<đîṽ ţŕàñšļàţé="ñö">...</đîṽ>` öŕ à ŕüļé: ▒

### ▒ Ƒŕàĝḿéñţš ▒

▒ À ƒŕàĝḿéñţ ŕööţ ŵîţĥ îñļîñé çöñţéñţ éẋţŕàçţš àš öñé ƃļöçķ, šàḿé àš à þŕöḿöţéđ çöñţàîñéŕ: ▒

### ▒ Ţéŕñàŕý àţţŕîƃüţé ṽàļüéš ▒

▒ Ŵĥéñ à ţŕàñšļàţàƃļé àţţŕîƃüţé'š ṽàļüé îš à ţéŕñàŕý ŵîţĥ _ƃöţĥ ƃŕàñçĥéš àš þļàîñ šţŕîñĝ ļîţéŕàļš_, éàçĥ ƃŕàñçĥ éẋţŕàçţš àš îţš öŵñ ƃļöçķ: ▒


▒ Ƃöţĥ `"Þŕöĵéçţ Ƒļöŵš"` àñđ `"Ƒļöŵš"` ĝéţ éẋţŕàçţéđ (ŵîţĥ `::0` / `::1` šüƒƒîẋéš öñ ţĥé çöñţéẋţ ţö ķééþ ţĥé ĥàšĥéš đîšţîñçţ). Àţ ŕüñţîḿé ţĥé ţŕàñšƒöŕḿ ŕéŵŕîţéš éàçĥ ļîţéŕàļ ƃŕàñçĥ ŵîţĥ îţš öŵñ `__ţ()` ļööķüþ; ţĥé çöñđîţîöñ šţîļļ ƒîŕéš àţ ŕéñđéŕ ţîḿé. ▒

▒ Ḿîẋéđ-šĥàþé ţéŕñàŕîéš (öñé ļîţéŕàļ, öñé çöḿþüţéđ, öŕ ƃöţĥ ţéḿþļàţéš) _àŕéñ'ţ_ šţàţîçàļļý éẋţŕàçţàƃļé — ţĥé ļîñţ ŕüļé [`ñö-ţéŕñàŕý-îñ-ţŕàñšļàţàƃļé-àţţŕ`](./linting#no-ternary-in-translatable-attr) ƒļàĝš ţĥéḿ. Ƒîẋ ƃý ŵŕàþþîñĝ ƃöţĥ ƃŕàñçĥéš ŵîţĥ `ţ()` šö ţĥé ţ-çàļļ ŵàļķéŕ þîçķš ţĥéḿ üþ: ▒

```tsx
// ✗ extractor can't see the template-literal branch

// ✓ both branches flow through the t() extraction path
<Input placeholder={disabled ? t("Disabled ({reason})", { reason }) : t("Enabled")} />
```

### ▒ Öþţîñĝ öüţ ŵîţĥ `ţŕàñšļàţé="ñö"` ▒

▒ Šţàñđàŕđ ĤŢḾĻ — ŵöŕķš öñ àñý éļéḿéñţ àñđ îţš đéšçéñđàñţš: ▒

```tsx

<section translate="no">
  <h2>Debug payload</h2>                       // ✗ not extracted
  <pre>{json}</pre>                            // ✗ not extracted
```

▒ Ƃöţĥ ţĥé éẋţŕàçţöŕ àñđ éṽéŕý ļîñţ ŕüļé îñ `@ñéöķàþî/î18ñ-ŕéàçţ-ļîñţ` ŵàļķ üþ ţĥé àñçéšţöŕ çĥàîñ ļööķîñĝ ƒöŕ `ţŕàñšļàţé="ñö"`. À šîñĝļé ḿàŕķéŕ àţ ţĥé ţöþ öƒ à šüƃţŕéé šîļéñçéš éṽéŕýţĥîñĝ îñšîđé — ñö ñééđ ţö šþŕîñķļé îţ öñ éṽéŕý éļéḿéñţ. ▒

▒ `ţŕàñšļàţé="ñö"` îš àļšö ţĥé ŕîĝĥţ àñšŵéŕ ŵĥéñ ýöü'ŕé îñţéñţîöñàļļý ŕéñđéŕîñĝ àñ àļŕéàđý-ţŕàñšļàţéđ ṽàļüé (šéé "Ḿöđüļé-ļéṽéļ `ţ()` ĝöţçĥà" ƃéļöŵ), öŕ ŵĥéñ ýöüŕ çöñţéñţ îš çöđé-ļîķé àñđ šĥöüļđñ'ţ ƃé ƒļàĝĝéđ àš ḿîššîñĝ ţŕàñšļàţîöñ. ▒

### ▒ Ŕüļéš ƒöŕ ŕéçüŕŕîñĝ þàţţéŕñš ▒

▒ Ƒöŕ þàţţéŕñš ŵĥéŕé ýöü đöñ'ţ ŵàñţ ţö šþŕîñķļé `ţŕàñšļàţé="ñö"` éṽéŕýŵĥéŕé, üšé ŕüļéš îñ ýöüŕ þļüĝîñ çöñƒîĝ: ▒

▒ Šéļéçţöŕš: þļàîñ ţàĝ (`çöđé`), çļàšš (`.çöđé-ƃļöçķ`), àţţŕîƃüţé þŕéšéñçé (`[đàţà-ţéšţîđ]`), öŕ àţţŕîƃüţé ṽàļüé (`[ŕöļé="àļéŕţ"]`). ▒

## ▒ Ŵĥàţ šţîļļ ñééđš éẋþļîçîţ ĥàñđļîñĝ ▒

▒ Ţĥé éẋţŕàçţöŕ çàñ öñļý šéé ŵĥàţ îţ çàñ šţàţîçàļļý ŕéàšöñ àƃöüţ. Ţĥéšé þàţţéŕñš šļîþ ţĥŕöüĝĥ — éàçĥ ĥàš à çàñöñîçàļ ƒîẋ. ▒

### ▒ Šţŕîñĝš îñ ĴŠ đàţà šţŕüçţüŕéš ▒

```tsx

  { value: "system", label: "System" }, // ✗ not extractable
  { value: "light", label: "Light" },
];

return THEMES.map(({ value, label }) => (
  <button>{label}</button> // ✗ label is an expression
));
```

▒ Ƒîẋ ŵîţĥ ţĥé [`ţ()` éšçàþé ĥàţçĥ](./t-escape-hatch): ▒

```tsx

  { value: "system", label: t("System") },
  { value: "light", label: t("Light") },
];
```

▒ Çàüĝĥţ ƃý ţĥé `þŕéƒéŕ-ţ-ƒöŕ-ļàƃéļ-þŕöþš` ļîñţ ŕüļé (öƒƒ ƃý đéƒàüļţ; öþţ îñ ṽîà `ŕéçöḿḿéñđéđŠţŕîçţ`). ▒

### ▒ Đýñàḿîç ļàƃéļ éẋþŕéššîöñš ▒

▒ Ţĥé ŕéñđéŕ-šîđé ḿîŕŕöŕ öƒ ţĥé àƃöṽé: `{obj.label}` / `{item.title}` ŕéñđéŕéđ àš ĴŠẊ ţéẋţ. Ţĥé éẋţŕàçţöŕ šééš àñ éẋþŕéššîöñ çöñţàîñéŕ àñđ éḿîţš à þļàçéĥöļđéŕ; ţĥé šţŕîñĝ îţ ŕéšöļṽéš ţö àţ ŕüñţîḿé ñéṽéŕ ƃéçöḿéš à ţŕàñšļàţîöñ üñîţ. ▒

```tsx

<h1>{meta.label}</h1>
```

▒ Ƒîẋ ƃý ŵŕàþþîñĝ ţĥé _šöüŕçé_ đàţà ŵîţĥ `ţ()` (šàḿé àš "Šţŕîñĝš îñ ĴŠ đàţà šţŕüçţüŕéš" àƃöṽé). Ţĥé ļîñţ ŕüļé [`þŕéƒéŕ-ţ-ƒöŕ-ļàƃéļ-éẋþŕ`](./linting#prefer-t-for-label-expr) ƒļàĝš ţĥé ŕéñđéŕ šîţé ţö þŕöḿþţ ţĥé ŕéƒàçţöŕ. ▒

### ▒ Ţéŕñàŕý ŵîţĥ šţŕîñĝ ļîţéŕàļš àš ĴŠẊ çĥîļđŕéñ ▒

```tsx

```

▒ ñéöķàþî-î18ñ ţŕéàţš ţĥé ŵĥöļé ţéŕñàŕý àš à šîñĝļé öþàǫüé þļàçéĥöļđéŕ — îţ ñéṽéŕ ļööķš îñšîđé àţ ţĥé ƃŕàñçĥéš. Ŵŕàþ éàçĥ ƃŕàñçĥ ŵîţĥ `ţ()`: ▒

```tsx

```

▒ Çàüĝĥţ ƃý [`ñö-ţéŕñàŕý-ļîţéŕàļš-îñ-ĵšẋ-çĥîļđ`](./linting#no-ternary-literals-in-jsx-child). Šàḿé ƒîẋ àþþļîéš ţö ţéḿþļàţé ļîţéŕàļš ŵîţĥ àçţüàļ çöþý: `` `Ļöàđîñĝ ${n}...` `` → `ţ("Ļöàđîñĝ {n}...", { n })`. ▒

### ▒ Ḿöđüļé-ļéṽéļ `ţ()` ĝöţçĥà ▒

▒ `ţ()` ŕéàđš ţĥé àçţîṽé đîçţîöñàŕý **àţ çàļļ ţîḿé**. À ḿöđüļé-ļéṽéļ çöñšţ éṽàļüàţéš öñçé, àţ îḿþöŕţ ţîḿé — ţýþîçàļļý _ƃéƒöŕé_ `ļöàđŢŕàñšļàţîöñš()` ĥàš ƒîñîšĥéđ. Ţĥé çöñšţ ƒŕééžéš àţ ţĥé ƒàļļƃàçķ ļàñĝüàĝé ƒöŕéṽéŕ. ▒

```tsx
// ✗ "Utility" will still say "Utility" in pseudo.
const categoryMeta = {
  utility: { label: t("Utility") },
  pipeline: { label: t("Pipeline") },
};
```

▒ Ƒîẋ: ŵŕàþ ţĥé ļööķüþ îñ à ƒüñçţîöñ ţĥàţ ŕüñš þéŕ ŕéñđéŕ. ▒

```tsx
// ✓ each render resolves the label against the current dict.
function categoryMeta(cat: string) {
  switch (cat) {
    case "utility":
      return { label: t("Utility") };
    case "pipeline":
      return { label: t("Pipeline") };
    // …
  }
}

function Chip({ cat }: { cat: string }) {
  const meta = categoryMeta(cat);
  return <span>{meta.label}</span>;
}
```

### ▒ Đöüƃļé-ţŕàñšļàţîöñ: àļŕéàđý-ţŕàñšļàţéđ ṽàļüéš îñšîđé ţŕàñšļàţàƃļé ƃļöçķš ▒

▒ À šüƃţļé þàţţéŕñ ţĥàţ öñļý šĥöŵš üþ îñ þšéüđö. Îƒ ýöü ŕéñđéŕ à `ţ()`-ŕéšöļṽéđ šţŕîñĝ àš à çĥîļđ öƒ àñ éļéḿéñţ ţĥé éẋţŕàçţöŕ àļšö ŵŕàþš àš à ƃļöçķ, þšéüđö-ţŕàñšļàţîöñ ĝéţš àþþļîéđ _ţŵîçé_ — ţĥé îññéŕ `ţ()` àđđš îţš ḿàŕķéŕš, àñđ ţĥé öüţéŕ éļéḿéñţ'š ţŕàñšļàţîöñ ŵŕàþš àŕöüñđ ţĥéḿ: ▒

```tsx

// Pseudo renders: ▒ ▒ Utility ▒ (32) ▒   ← two layers of wrapping
```

▒ Ƒîẋ: ḿàŕķ ţĥé öüţéŕ éļéḿéñţ `ţŕàñšļàţé="ñö"` šö ţĥé îññéŕ `ţ()` çàļļ öŵñš ţĥé ţŕàñšļàţîöñ. ▒


▒ Àļţéŕñàţîṽé: ļîƒţ ţĥé ŵĥöļé šţŕîñĝ îñţö à šîñĝļé `ţ()` çàļļ ŵîţĥ þļàçéĥöļđéŕš — ƃüţ ţĥàţ'š àŵķŵàŕđ ŵĥéñ öñé ĥàļƒ îš à ţŕàñšļàţéđ ļàƃéļ àñđ ţĥé öţĥéŕ îš à ñüḿéŕîç çöüñţ. ▒

## ▒ Šüḿḿàŕý: ŵĥàţ ĝöéš ŵĥéŕé ▒

| Source pattern                            | Extracted? | Notes                                                                    |
| ----------------------------------------- | ---------- | ------------------------------------------------------------------------ |
| `<h1>Hello</h1>`                          | yes        | standard translatable element                                            |
| `<div>Hello</div>`                        | yes        | auto-promoted silently                                                   |
| `<>Hello <b>you</b></>`                   | yes        | fragment root; descriptor is `fragment`                                  |
| `<Button><Icon/>Save</Button>`            | yes        | "Save" extracts with `{=m0}` standalone for the icon                     |
| `<TabsTrigger>Hello</TabsTrigger>`        | yes        | warning suggests `componentMap`                                          |
| `<PageHeader title="Hi" />`               | yes        | `title` is an HTML attribute — any element                              |
| `<PageHeader title={cond ? "A" : "B"} />` | yes        | both branches — one block each                                           |
| `<MyComp description="Hi" />`             | yes        | `description` is a convention prop — components only                     |
| `<div label="draft-pending" />`           | no         | convention prop on a plain element — not copy                            |
| `<p>Click <a>here</a></p>`                | yes        | one block, `<a>` becomes paired `{=m0}…{/=m0}`                           |
| `<code>foo</code>`                        | no         | non-translatable element                                                 |
| `<h1 translate="no">X</h1>`               | no         | explicit opt-out (suppresses lint too)                                   |
| `<button>{label}</button>`                | no         | bare expression — use `t()` on the source                                |
| `<button>{obj.label}</button>`            | no         | flagged by `prefer-t-for-label-expr` — wrap the source                   |
| `<button>{cond ? "A" : "B"}</button>`     | no         | flagged by `no-ternary-literals-in-jsx-child` — wrap branches with `t()` |
| `<div>{cond && 'Hi'}</div>`               | no         | expression — use `t()`                                                   |
