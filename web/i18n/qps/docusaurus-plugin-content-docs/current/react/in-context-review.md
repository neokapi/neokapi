# ▒ Îñ-çöñţéẋţ ŕéṽîéŵ ▒

Ŕéṽîéŵ ḿöđé þüţš ţĥé ŕéṽîéŵ ƃàçķ öñ ţĥé àþþ: ŕüñ îţ, ĥöļđ ÀĻŢ, àñđ éṽéŕý ţŕàñšļàţàƃļé šţŕîñĝ öñ ţĥé þàĝé ƃéçöḿéš šöḿéţĥîñĝ ýöü çàñ îñšþéçţ àñđ ƒîẋ îñ þļàçé. ▒

## ▒ Ŕéṽîéŵ à šţŕîñĝ ▒

▒ Ĥöļđ **ÀĻŢ** — ĥöṽéŕîñĝ ñöŵ öüţļîñéš éṽéŕý ţŕàñšļàţàƃļé éļéḿéñţ. **ÀĻŢ+çļîçķ** öñé ţö öþéñ îţš þàñéļ: ▒

- ▒ **Šöüŕçé** — ţĥé öŕîĝîñàļ ţéẋţ, ŵîţĥ îţš ļîñķš, ƃöļđ šþàñš, àñđ þļàçéĥöļđéŕš šĥöŵñ ţĥé ŵàý à ţŕàñšļàţöŕ šééš ţĥéḿ. ▒
- ▒ **Ţàŕĝéţ** — ţĥé çüŕŕéñţ ţŕàñšļàţîöñ, éđîţàƃļé. ▒
- ▒ **Ñöţé** — ţĥé çöñţéẋţ ţĥé đéṽéļöþéŕ ļéƒţ, îƒ àñý (`đàţà-î18ñ-ñöţé`, öŕ `ţ(ţéẋţ, çöñţéẋţ)`). ▒
- ▒ **Ƒîñđîñĝš** — ţéŕḿîñöļöĝý àñđ ǪÀ îššüéš àĝàîñšţ ţĥîš šţŕîñĝ. ▒

▒ Ţýþé à ƒîẋ, šàṽé, àñđ ţĥé àþþ ŕéþàîñţš îḿḿéđîàţéļý. Ýöü àŕé ñöţ þŕéṽîéŵîñĝ ţĥé çĥàñĝé; ýöü àŕé ļööķîñĝ àţ îţ. ▒

▒ Ţĥé ƒîẋ îš ŵŕîţţéñ îñţö ţĥé `.ķƃƒ.ĵšöñ` ƒîļé ţĥé šţŕîñĝ çàḿé ƒŕöḿ — šö îţ šĥöŵš üþ àš à ļîñé îñ `ĝîţ đîƒƒ`, ţŕàṽéļš ţĥŕöüĝĥ ŕéṽîéŵ îñ à þüļļ ŕéǫüéšţ ļîķé àñý öţĥéŕ çĥàñĝé, àñđ îš þîçķéđ üþ ƃý ţĥé ñéẋţ `ñéöķàþî-î18ñ çöḿþîļé` ŵîţĥ ñö éẋţŕà šţéþ. À ŕéṽîéŵéŕ'š éđîţ ţàķéš éẋàçţļý ţĥé šàḿé þàţĥ àš à ţŕàñšļàţöŕ'š, ƃéçàüšé îţ îš ţĥé šàḿé ƒîļé. ▒

## ▒ Ĥéàđ àñđ ŠÉÖ šţŕîñĝš ▒

▒ Ţĥé þàĝé ţîţļé, ḿéţà đéšçŕîþţîöñ, àñđ Öþéñ Ĝŕàþĥ / Ţŵîţţéŕ çàŕđ šţŕîñĝš çàŕŕý ñö ŕéñđéŕéđ ţéẋţ ñöđé, šö ţĥéŕé îš ñöţĥîñĝ öñ ţĥé þàĝé ţö ĥöļđ ÀĻŢ àñđ çļîçķ — ýéţ ţĥéý àŕé öƒţéñ ţĥé šţŕîñĝš à šéàŕçĥ ŕéšüļţ öŕ à šĥàŕéđ ļîñķ šĥöŵš ƒîŕšţ. Ţŕàñšļàţé ţĥéḿ ţĥŕöüĝĥ ţĥé ĥéàđ ĥööķš àñđ ţĥéý ƃéçöḿé ŕéṽîéŵàƃļé îñ à þàñéļ öƒ ţĥéîŕ öŵñ. ▒

```tsx
import {
  useTranslatedTitle,
  useTranslatedDescription,
  useTranslatedMeta,
} from "@neokapi/i18n-react/head";

function Head() {
  useTranslatedTitle("Dashboard · Acme");
  useTranslatedDescription("Manage your team, projects, and billing.");
  useTranslatedMeta("Dashboard · Acme", { property: "og:title" });
  return null;
}
```

▒ Éàçĥ ĥööķ ţŕàñšļàţéš îţš šöüŕçé ţĥŕöüĝĥ ţĥé ŕüñţîḿé đîçţîöñàŕý — ţĥé šàḿé ļööķüþ `ţ()` üšéš — šéţš ţĥé ŕéàļ ĥéàđ éļéḿéñţ, àñđ ŕéĝîšţéŕš ţĥé šţŕîñĝ ƒöŕ ŕéṽîéŵ. Ñöţĥîñĝ šçŕàþéš àŕƃîţŕàŕý ĥéàđ ḿàŕķüþ; öñļý šţŕîñĝš ţĥé þîþéļîñé ţŕàñšļàţéđ àþþéàŕ. ▒

▒ À **ĥéàđ/ŠÉÖ** ƃüţţöñ àþþéàŕš îñ ţĥé ŕéṽîéŵ ţööļƃàŕ ŵĥéñéṽéŕ à þàĝé ĥàš šüçĥ šţŕîñĝš. Îţ öþéñš à þàñéļ ļîšţîñĝ éàçĥ öñé — îţš šļöţ (`ţîţļé`, `đéšçŕîþţîöñ`, `öĝ:ţîţļé`, …), ţĥé šöüŕçé, àñđ ţĥé çüŕŕéñţ ţàŕĝéţ — ŵîţĥ ţĥé šàḿé éđîţàƃļé ƒîéļđ àñđ šàṽé ţĥé îñļîñé þàñéļ üšéš. Àñ éđîţ ŵŕîţéš ƃàçķ ţĥŕöüĝĥ ţĥé šàḿé `.ķƃƒ.ĵšöñ` ƒîļé àñđ ŕéþàîñţš ţĥé ĥéàđ îñ þļàçé. Ŵĥéñ à þàĝé ŕéĝîšţéŕš ñö ĥéàđ šţŕîñĝš, ţĥé ƃüţţöñ šţàýš ĥîđđéñ. ▒

▒ Ĥéàđ ţŕàñšļàţîöñ ŕéšöļṽéš ţĥŕöüĝĥ ţĥé ŕüñţîḿé đîçţîöñàŕý, šö îţ àþþļîéš îñ ÖŢÀ / [ŕüñţîḿé ḿöđé](./modes). Îđéñţîçàļļý-ŵöŕđéđ šļöţš — à `<ţîţļé>` àñđ îţš `öĝ:ţîţļé` — šĥàŕé öñé ţŕàñšļàţîöñ. ▒

## ▒ Šéé ţéŕḿîñöļöĝý àñđ ǪÀ öñ ţĥé þàĝé ▒

▒ Ŕüñ ķàþî'š çĥéçķš àĝàîñšţ ţĥé šàḿé `î18ñ/` đîŕéçţöŕý àñđ ţĥéîŕ ƒîñđîñĝš àþþéàŕ öñ ţĥé ŕéñđéŕéđ ţéẋţ: ▒


▒ Àñ àþþŕöṽéđ ţéŕḿ ţĥàţ ŵàšñ'ţ üšéđ, à þļàçéĥöļđéŕ ţĥàţ ŵéñţ ḿîššîñĝ îñ ţŕàñšļàţîöñ, à šţŕîñĝ ţĥàţ ŕüñš 60% ļöñĝéŕ ţĥàñ îţš šöüŕçé àñđ îš àƃöüţ ţö ƃŕéàķ ţĥé ƃüţţöñ îţ ļîṽéš îñ — éàçĥ îš ḿàŕķéđ öñ ţĥé ŵöŕđš îţ'š àƃöüţ, îñ ţĥé þļàçé îţ ĥàþþéñš. Ŕé-ŕüñ à çĥéçķ ŵĥîļé ţĥé àþþ îš öþéñ àñđ ţĥé ḿàŕķš üþđàţé; ýöü đöñ'ţ ñééđ ţö ŕéšţàŕţ àñýţĥîñĝ. ▒

## ▒ Ŕéṽîéŵ öñ šţàţîçàļļý-ŕéñđéŕéđ þàĝéš ▒

▒ Ţĥé ŕéṽîéŵ îđéñţîƒîéŕ îš à **çöñţéñţ ĥàšĥ**, ñöţ à ŕüñţîḿé àŕţîƒàçţ: `đàţà-ķàþî-îđ` îš ţĥé šàḿé ŵĥéţĥéŕ ţĥé ƃüîļđ [îñļîñéš](./modes) ţĥé ţŕàñšļàţîöñ (žéŕö-ŕüñţîḿé ŠŠĜ/ŠŠŔ) öŕ éḿîţš à ŕüñţîḿé `ţ()` çàļļ. Šö ŕéṽîéŵ îš ŕéñđéŕ-ḿöđé-îñđéþéñđéñţ — îţ ŵöŕķš öñ à ƒüļļý šţàţîç þàĝé ŵîţĥ ñö àþþ î18ñ ŕüñţîḿé. ▒

▒ Ţüŕñ `ŕéṽîéŵ: ţŕüé` öñ ƒöŕ àñ **îñļîñé** (öŕ ŠŠĜ/ŠŠŔ) ƃüîļđ àñđ ţĥé þļüĝîñ đöéš ţŵö ţĥîñĝš ŕéĝàŕđļéšš öƒ ḿöđé: îţ šţàḿþš `đàţà-ķàþî-îđ` îñţö ţĥé ƃàķéđ ĤŢḾĻ, àñđ îţ éḿîţš `ţŕàñšļàţîöñš/ŕéṽîéŵ.ĵšöñ` — à ŕéàđ-öñļý ḿàñîƒéšţ öƒ šöüŕçé, ţàŕĝéţ, àñđ ļöçàţîöñ ƒöŕ éṽéŕý šţŕîñĝ öñ ţĥé þàĝé. Ţĥàţ îš éṽéŕýţĥîñĝ à **ĥöšţéđ öṽéŕļàý** ñééđš: ▒

```ts
import { initKapiReviewHosted } from "@neokapi/i18n-react/review/hosted";

initKapiReviewHosted(); // read-only; fetches translations/review.json
```

▒ Ŵîţĥ ñöţĥîñĝ ƃüţ à šţàţîç đéþļöý — ñö đéṽ šéŕṽéŕ, ñö ƃàçķéñđ — à ŕéṽîéŵéŕ çàñ đééþ-ļîñķ ţö à šţŕîñĝ (`?ķàþî-ƒöçüš=<ĥàšĥ>`), öþéñ ţĥé ŵĥöļé-þàĝé îñđéẋ (`?ķàþî-ŕéṽîéŵ`), àñđ îñšþéçţ àñý šţŕîñĝ'š šöüŕçé àñđ ţàŕĝéţ îñ çöñţéẋţ. Ţĥîš îš ţĥé "çļîçķ ƒŕöḿ ţĥé þļàţƒöŕḿ îñţö ţĥé ļîṽé šîţé" þàţĥ. ▒

▒ Ţö ļéţ à ŕéṽîéŵéŕ **éđîţ** öñ ţĥàţ šţàţîç þàĝé, þàšš `éđîţ: ţŕüé` àñđ àñ éñđþöîñţ ţĥàţ šþéàķš ţĥé ŕéṽîéŵ-šţöŕé þŕöţöçöļ (à šţàĝîñĝ đéþļöýḿéñţ öƒ ţĥé đéṽ ḿîđđļéŵàŕé, öŕ à þŕöẋîéđ ŕéṽîéŵ ƃàçķéñđ): ▒

```ts

```

▒ Šàṽîñĝ ÞÜŢš ţö `{endpoint}/{hash}` — ţĥé šàḿé ŵŕîţé-ƃàçķ à ƃöđý šţŕîñĝ üšéš — àñđ ŕéþàîñţš ţĥé éļéḿéñţ'š ţéẋţ îñ þļàçé, îñđéþéñđéñţ öƒ àñý àþþ î18ñ ŕüñţîḿé. Ŕéþàîñţ îš ţéẋţ-öñļý: à šţŕîñĝ ŵîţĥ îñļîñé ḿàŕķüþ (à ļîñķ, à ƃöļđ šþàñ) öŕ àñ ÎÇÜ þļüŕàļ šàṽéš ţö ţĥé šţöŕé ƃüţ îš ñöţ ŕéþàîñţéđ ļîṽé; à ŕéļöàđ þîçķš üþ ţĥé ŕéàļ ŕéñđéŕîñĝ. Ƒöŕ à ḿàñîƒéšţ ţĥàţ àļšö çàŕŕîéš éṽéŕý ļöçàļé'š ţàŕĝéţ àñđ ţĥé ţéŕḿîñöļöĝý/ǪÀ ƒîñđîñĝš, ĝéñéŕàţé îţ öṽéŕ ţĥé ŵĥöļé ĶƂƑ ţŕéé îñšţéàđ: ▒

