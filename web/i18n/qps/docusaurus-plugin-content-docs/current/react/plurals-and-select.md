# ▒ Þļüŕàļš àñđ šéļéçţ ▒

▒ Çöüñţ-àŵàŕé àñđ çĥöîçé-ƃàšéđ ţéẋţ, àüţĥöŕéđ îñ Ŕéàçţ ŵîţĥ þéŕ-ƒöŕḿ çĥîļđŕéñ. Ñö ŕàŵ ÎÇÜ šţŕîñĝš îñ ýöüŕ šöüŕçé. ▒

## ▒ Þļüŕàļš — ţĥé àüţĥöŕîñĝ ƒöŕḿ ▒

```tsx
import { Plural, Zero, One, Two, Few, Many, Other } from "@neokapi/i18n-react/runtime";

  <Plural count={n}>
    <Zero>No messages</Zero>
    <One>1 message</One>
    <Other>{n} messages</Other>
  </Plural>

```

▒ Àţ ŕéñđéŕ ţîḿé, `<Þļüŕàļ>` çöñšüļţš `Îñţļ.ÞļüŕàļŔüļéš` ƒöŕ ţĥé àçţîṽé ļöçàļé àñđ þîçķš ţĥé ḿàţçĥîñĝ ƒöŕḿ. Ƒöŕ Éñĝļîšĥ `ñ = 1` ŕéšöļṽéš ţö `<Öñé>`, éṽéŕýţĥîñĝ éļšé ţö `<Öţĥéŕ>`. Ƒöŕ Àŕàƃîç, `<Žéŕö>`, `<Öñé>`, `<Ţŵö>`, `<Ƒéŵ>`, `<Ḿàñý>`, `<Öţĥéŕ>` àļļ ĥàṽé đîšţîñçţ ŕüļéš. ▒

## ▒ Šéļéçţ — çĥöîçé-ƃàšéđ ţéẋţ ▒

```tsx
import { Select, Case, Other } from "@neokapi/i18n-react/runtime";

<p>
  <Select value={role}>
    <Case when="admin">Admin access</Case>
    <Case when="editor">Editor access</Case>
    <Case when="viewer">Viewer access</Case>
    <Other>No access</Other>
```

▒ `<Šéļéçţ>` þîçķš ţĥé `<Çàšé>` ŵĥöšé `ŵĥéñ` þŕöþ éǫüàļš ţĥé šöüŕçé ṽàļüé, öŕ ƒàļļš ƃàçķ ţö `<Öţĥéŕ>`. ▒

## ▒ Ŵĥý çĥîļđŕéñ, ñöţ þŕöþš ▒

▒ Ţŕàđîţîöñàļ î18ñ ļîƃŕàŕîéš éẋþŕéšš þļüŕàļš àš à šîñĝļé ÎÇÜ ḿéššàĝé: ▒

```text

```

▒ Ţĥàţ ŵöŕķš, ƃüţ ḿîẋéš ţĥé šöüŕçé-ļàñĝüàĝé ƒöŕḿš îñţö àñ öþàǫüé šţŕîñĝ ļîţéŕàļ. ñéöķàþî-î18ñ ķééþš éàçĥ ƒöŕḿ àš à ĴŠẊ çĥîļđ šö: ▒

- ▒ **Šöüŕçé ŕéàđàƃîļîţý** — ţĥé Éñĝļîšĥ ƒöŕḿš ļööķ ļîķé Éñĝļîšĥ îñ šöüŕçé, ţŕàñšļàţöŕš šéé Éñĝļîšĥ îñ ţĥé éẋţŕàçţ. ▒
- ▒ **Îñļîñé éļéḿéñţš þéŕ ƒöŕḿ** — ýöü çàñ ŵŕîţé `<Öţĥéŕ><šţŕöñĝ>{n}</šţŕöñĝ> îţéḿš</Öţĥéŕ>` ŵîţĥ ţĥé šţŕöñĝ ţàĝ þŕéšéŕṽéđ àš à þöšîţîöñ ţöķéñ. ÎÇÜ đöéšñ'ţ ḿöđéļ ţĥàţ ñàţüŕàļļý. ▒
- ▒ **Þļàçéĥöļđéŕš þéŕ ƒöŕḿ** — `{n}` îš àñ éẋþŕéššîöñ, ĥàñđļéđ ƃý ţĥé šàḿé þļàçéĥöļđéŕ ḿàçĥîñéŕý àš àñý ĴŠẊ ţéẋţ. ▒

▒ Üñđéŕ ţĥé ĥööđ ţĥé éẋţŕàçţöŕ éḿîţš ţĥé çàñöñîçàļ ÎÇÜ ţéḿþļàţé ţĥàţ ţŕàñšļàţöŕš ķñöŵ. Šöüŕçé àüţĥöŕš ŵöŕķ îñ Ŕéàçţ; ţŕàñšļàţöŕš ŵöŕķ îñ ţĥéîŕ ÇÀŢ ţööļ àĝàîñšţ ÎÇÜ. Ƃöţĥ ṽîéŵš àŕé çöŕŕéçţ. ▒

▒ Ḿöṽé ţĥé çöüñţ àñđ çĥàñĝé ţĥé ļöçàļé ţö šéé ŵĥîçĥ ƒöŕḿ `Îñţļ.ÞļüŕàļŔüļéš` ŕéšöļṽéš — ţĥé šàḿé ļööķüþ `<Þļüŕàļ>` đöéš àţ ŕéñđéŕ ţîḿé — ñéẋţ ţö ţĥé ÎÇÜ ţéḿþļàţé ţĥé éẋţŕàçţöŕ éḿîţš: ▒

## ▒ Ḿîẋîñĝ îñļîñé éļéḿéñţš îñšîđé à þļüŕàļ ƒöŕḿ ▒

```tsx

    <Other>
```

▒ Éàçĥ ƒöŕḿ îš éẋţŕàçţéđ àš à ţýþéđ ŕüñ šéǫüéñçé — `<šţŕöñĝ>` ƃéçöḿéš à þöšîţîöñ ţöķéñ (`{=m0}`), `{items.length}` ƃéçöḿéš à þļàçéĥöļđéŕ (`{items.length}` öŕ đéđüþéđ ļîķé `{itemsLength}`). Ţĥé ţŕàñšļàţöŕ çàñ ŕéöŕđéŕ ţĥé ƃöļđ éļéḿéñţ ƒŕééļý ŵîţĥîñ éàçĥ ƒöŕḿ. ▒

## ▒ Ŵĥîçĥ ƒöŕḿš ţö đéçļàŕé ▒

▒ Üšé ţĥé šüþéŕšéţ öƒ ƒöŕḿš ýöüŕ þŕöđüçţ àçţüàļļý šĥîþš. Ļàñĝüàĝéš ýöü đöñ'ţ ţàŕĝéţ ţöđàý çàñ šţîļļ ƃé àđđéđ ļàţéŕ ŵîţĥöüţ šöüŕçé çĥàñĝéš: àđđ ţĥé ţŕàñšļàţîöñ îñ ţĥé ÇÀŢ ţööļ, ţĥé ŕüñţîḿé þîçķš ţĥé ŕîĝĥţ ƒöŕḿ. ▒

| Language                  | Forms used                                   |
| ------------------------- | -------------------------------------------- |
| English                   | `one`, `other`                               |
| French                    | `one`, `other`                               |
| Russian                   | `one`, `few`, `many`, `other`                |
| Arabic                    | `zero`, `one`, `two`, `few`, `many`, `other` |
| Japanese, Korean, Chinese | `other` only                                 |

▒ Šöüŕçé àüţĥöŕš üšüàļļý öñļý ñééđ `öñé` + `öţĥéŕ`, þļüš öþţîöñàļ `žéŕö` ƒöŕ ÜẊ þöļîšĥ ("Ñö ḿéššàĝéš" ṽš. "0 ḿéššàĝéš"). Ţŕàñšļàţöŕš ƒîļļ ţĥé ŕéšţ þéŕ ļöçàļé. ▒

## ▒ `<Þļüŕàļ>` ŵîţĥ à šöüŕçé þîṽöţ ▒

▒ Šöḿéţîḿéš ţĥé çöüñţ ṽàŕîàƃļé'š ñàḿé đöéšñ'ţ ḿàţçĥ ŵĥàţ ýöü ŵàñţ ţŕàñšļàţöŕš ţö ŕéƒéŕéñçé: ▒

▒ Ţĥé þîṽöţ ṽàŕîàƃļé ƃéçöḿéš à þļàçéĥöļđéŕ ñàḿéđ àƒţéŕ ţĥé éẋþŕéššîöñ (`îţéḿš.ļéñĝţĥ` → `ļéñĝţĥ`). Îƒ ţĥàţ'š çöñƒüšîñĝ ƒöŕ ţŕàñšļàţöŕš, ŕéñàḿé ṽîà à ļöçàļ: ▒

## ▒ Ţŕàñšļàţöŕ-àüţĥöŕéđ þļüŕàļš ▒

▒ Ñöţ éṽéŕý ļàñĝüàĝé ñééđš þļüŕàļš ƒöŕ éṽéŕý šţŕîñĝ. Îţàļîàñ üšéš ţĥé šàḿé ƒöŕḿ ƒöŕ 1 ṽš ḿàñý îñ šöḿé çöñšţŕüçţš, Ĵàþàñéšé ĥàš öñļý öñé ƒöŕḿ, ŵĥîļé Ĝéŕḿàñ ḿîĝĥţ ŵàñţ à çöüñţ ƒöŕḿ ŵĥéŕé Éñĝļîšĥ đîđñ'ţ. ▒

▒ ñéöķàþî-î18ñ'š éđîţöŕ ÜÎ (`<ÞļüŕàļŢàŕĝéţÉđîţöŕ>`, šĥîþþéđ ŵîţĥ `@ñéöķàþî/üî-þŕîḿîţîṽéš`) ļéţš ţŕàñšļàţöŕš **üþĝŕàđé** à ƒļàţ ţàŕĝéţ îñţö à þéŕ-ƒöŕḿ ţàŕĝéţ ŵîţĥöüţ àñý šöüŕçé çĥàñĝé. À ţŕàñšļàţöŕ'š Ĝéŕḿàñ ţàŕĝéţ ƒöŕ `<þ>Ýöü ĥàṽé {n} ḿéššàĝéš</þ>` çàñ ƃéçöḿé: ▒

## ▒ Ŕüñţîḿé ŕéšöļüţîöñ ▒

Ţĥîš îš ţĥé öñé đöçüḿéñţéđ éẋçéþţîöñ ţö îñļîñé ḿöđé'š žéŕö-ŕüñţîḿé ŕüļé (šéé [Ŕüñţîḿé ṽš. îñļîñé ḿöđéš](./modes#the-icu-exception)). ▒
