## ▒ Ŕüñţîḿé ḿöđé ▒


### ▒ Ļàžý ļöàđîñĝ þéŕ ŕöüţé (çöđé šþļîţţîñĝ) ▒

▒ Ƒöŕ ļàŕĝéŕ àþþš, ţĥé šîñĝļé-çàţàļöĝ-þéŕ-ļöçàļé ḿöđéļ đöŵñļöàđš éṽéŕý šţŕîñĝ éṽéñ ƒöŕ ŕöüţéš ţĥé üšéŕ ñéṽéŕ ṽîšîţš. Ţĥé þļüĝîñ + ŕüñţîḿé çàñ šþļîţ ţŕàñšļàţîöñš àļöñĝ ţĥé šàḿé ļîñéš ţĥé ƃüñđļéŕ šþļîţš çöđé: ▒

▒ Îñļîñé ḿöđé îš žéŕö-ŕüñţîḿé ŵîţĥ öñé đöçüḿéñţéđ éẋçéþţîöñ: **`<Þļüŕàļ>`, `<Šéļéçţ>`, àñđ àñý šţŕîñĝ à ţŕàñšļàţöŕ ĝàṽé àñ ÎÇÜ ƒöŕḿàţ ţö ķééþ à ŕüñţîḿé çàļļ.** ▒

▒ Ţĥé ŕéàšöñ îš šţŕüçţüŕàļ. À þļüŕàļ'š þîṽöţ — ţĥé çöüñţ — îš öñļý ķñöŵñ ŵĥéñ ţĥé çöḿþöñéñţ ŕéñđéŕš, šö ñö ƃüîļđ šţéþ çàñ þîçķ ţĥé ƒöŕḿ. Îñļîñé ḿöđé đöéš ţĥé ĥàļƒ îţ çàñ: ţĥé ţŕàñšļàţéđ ÎÇÜ ţéḿþļàţé îš ƃàķéđ îñţö ţĥé çàļļ àš îţš ƒàļļƃàçķ, šö ţĥéŕé'š ñö đîçţîöñàŕý ţö ƒéţçĥ àñđ ñö ñéţŵöŕķ öñ ţĥé çŕîţîçàļ þàţĥ. Ŵĥàţ šţàýš îš ţĥé ~2 ķƂ ÎÇÜ ŕéšöļṽéŕ. ▒

▒ Îƒ ýöü ĥàṽé ñö þļüŕàļš àñđ ñö ÎÇÜ ƒöŕḿàţš, îñļîñé ḿöđé šĥîþš ñöţĥîñĝ. Îƒ ýöü ĥàṽé öñé, ýöü šĥîþ ţĥé ŕéšöļṽéŕ. Îţ îš ñéṽéŕ îñṽàļîđ ĴŠẊ àñđ ñéṽéŕ à šîļéñţ ƒàļļƃàçķ ţö šöüŕçé. ▒

### ▒ Ŵĥéñ îñļîñé ḿöđé ƒîţš ▒

- ▒ Ýöü šĥîþ þéŕ-ļöçàļé ƃüîļđš (`ŵŵŵ-ƒŕ.éẋàḿþļé.çöḿ`, `ŵŵŵ-đé.éẋàḿþļé.çöḿ`). ▒
- ▒ Ýöü çàŕé àƃöüţ ƒîŕšţ-þàîñţ ƃüñđļé šîžé — ñö ŕüñţîḿé, ñö đîçţ ƒéţçĥ. ▒

## ▒ Ĥýƃŕîđ: îñļîñé çöŕé, ŕüñţîḿé öþţîöñàļ ļöçàļéš ▒

▒ À çöḿḿöñ þàţţéŕñ îš ţö îñļîñé ţĥé þŕîḿàŕý ļöçàļé àţ ƃüîļđ ţîḿé (šö ţĥé đéƒàüļţ ḿàŕķéţ ļöàđš îñšţàñţļý) àñđ ḿàķé šéçöñđàŕý ļöçàļéš àṽàîļàƃļé ṽîà ţĥé ŕüñţîḿé đîçţ: ▒

▒ Ḿîẋîñĝ ḿöđéš ŵîţĥîñ à šîñĝļé ƃüîļđ îš ñöţ šüþþöŕţéđ — ýöü þîçķ öñé þéŕ đéþļöý. ▒

## ▒ Ḿöđé çöḿþàŕîšöñ ▒

|                         | runtime                     | inline                                       |
| ----------------------- | --------------------------- | -------------------------------------------- |
| Number of builds        | 1                           | 1 per locale                                 |
| Runtime bundle cost     | ~2 kB                       | 0, or ~2 kB if you use ICU / plurals         |
| Dict fetch at runtime   | yes (per locale)            | no                                           |
| Missing translation     | fallback to source text     | warn or error at build                       |
| Hot-swap locale in-page | yes                         | full page reload / swap bundle               |
| Best for                | app shells, SaaS dashboards | marketing sites, SSR, SSG, locale-per-domain |
