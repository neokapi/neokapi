# ▒ Ţéŕḿîñöļöĝý Đàţà Ḿöđéļ ▒

▒ Ţĥîš ñöţé þŕöṽîđéš îḿþļéḿéñţàţîöñ đéţàîļš ƒöŕ [Ç-08](/contribute/architecture/context/c-08-terms). ▒

## ▒ Đàţà Ḿöđéļ: Çöñçéþţ-Öŕîéñţéđ ▒

▒ Ţĥé çöŕé đàţà ḿöđéļ îš çöñçéþţ-öŕîéñţéđ, ƒöļļöŵîñĝ ŢƂẊ þŕîñçîþļéš. À Çöñçéþţ ĝŕöüþš ţéŕḿš àçŕöšš ļàñĝüàĝéš, éàçĥ ŵîţĥ çöñţéẋţ đîḿéñšîöñš: ▒

```go
type Term struct {
    Text           string           // the term text
    Locale         model.LocaleID   // language/locale
    Status         model.TermStatus // lifecycle status (proposed, approved, preferred,
                                    // admitted, deprecated, forbidden)
    PartOfSpeech   string           // noun, verb, adjective, etc.
    Gender         string           // grammatical gender (if applicable)
    Note           string           // usage note or context
    CompetitorTerm bool             // true if this is a competitor brand term
}

type Concept struct {
    ID         string            // unique concept identifier
    ProjectID  string            // project scope (empty = workspace-scoped)
    Domain     string            // subject field (software, medical, legal, etc.)
    Definition string            // language-neutral definition
    Source     TermSource        // "terminology" or "brand_vocabulary"
    Terms      []Term            // terms across locales
    Properties map[string]string // extensible metadata
    CreatedAt  time.Time
    UpdatedAt  time.Time
}
```

▒ `ŢéŕḿŠöüŕçé` đîšţîñĝüîšĥéš ţŕàđîţîöñàļ ţéŕḿîñöļöĝý
(`ŢéŕḿŠöüŕçéŢéŕḿîñöļöĝý`) ƒŕöḿ ṽöîçé ṽöçàƃüļàŕý (`ŢéŕḿŠöüŕçéƂŕàñđṼöçàƃüļàŕý`),
šö ţĥé ţŵö þöþüļàţîöñš çàñ šĥàŕé öñé ţéŕḿš šţöŕé ŵĥîļé šţàýîñĝ ƒîļţéŕàƃļé. ▒

▒ Þŕöĝŕéššîṽé đîšçļöšüŕé: ÇŠṼ îḿþöŕţ àüţö-çŕéàţéš Çöñçéþţš ŵîţĥ à šîñĝļé þŕéƒéŕŕéđ Ţéŕḿ þéŕ ļöçàļé -- ñö éẋţŕà çöḿþļéẋîţý ŕéǫüîŕéđ. ▒

▒ Îḿþöŕţ àñđ éẋþöŕţ àŕé šţàñđàļöñé ƒüñçţîöñš ŕàţĥéŕ ţĥàñ îñţéŕƒàçé ḿéţĥöđš:
`ÎḿþöŕţĴŠÖÑ`/`ÉẋþöŕţĴŠÖÑ`, `ÎḿþöŕţÇŠṼ`/`ÉẋþöŕţÇŠṼ`, àñđ `ÎḿþöŕţŢƂẊ`/`ÉẋþöŕţŢƂẊ`
(ţĥé ÎŠÖ ŢƂẊ îñţéŕçĥàñĝé ƒöŕḿàţ, ŵîţĥ `ŢƂẊÎḿþöŕţÖþţîöñš`/`ŢƂẊÉẋþöŕţÖþţîöñš`).
Ƒŕàḿéŵöŕķ ƃàçķéñđš: îñ-ḿéḿöŕý (ÇĻÎ ƃàţçĥ) àñđ ŠǪĻîţé (þéŕšîšţéñţ). Ţĥé
`Ţéŕḿîñöļöĝý` îñţéŕƒàçé šüþþöŕţš šéŕṽéŕ-šîđé ƃàçķéñđš ƒöŕ ḿüļţî-üšéŕ đéþļöýḿéñţš. ▒

## ▒ Ƒüžžý Ḿàţçĥîñĝ àñđ Šéàŕçĥ ▒

▒ Ţéŕḿ ļööķüþ üšéš à ţîéŕéđ ḿàţçĥîñĝ þîþéļîñé: éẋàçţ -> ñöŕḿàļîžéđ -> ƒüžžý. Ƒüžžý ḿàţçĥîñĝ üšéš ţŕîĝŕàḿ-ƃàšéđ çàñđîđàţé ŕéţŕîéṽàļ ţö àṽöîđ ƒüļļ ţàƃļé šçàñš: ▒

- ▒ **ŠǪĻîţé**: ƑŢŠ5 `ţŕîĝŕàḿ` ţöķéñîžéŕ öñ `ţéẋţ_ļöŵéŕ` çöļüḿñ, šýñçéđ ṽîà ţŕîĝĝéŕš. Ƒàļļš ƃàçķ ţö ļéñĝţĥ-ƃàšéđ þŕé-ƒîļţéŕîñĝ îƒ ƑŢŠ5 îš üñàṽàîļàƃļé. ▒
- ▒ **ÞöšţĝŕéŠǪĻ**: þĝ_ţŕĝḿ ĜÎÑ îñđéẋ öñ `ţéẋţ_ļöŵéŕ` çöļüḿñ, üšîñĝ ţĥé `%` šîḿîļàŕîţý öþéŕàţöŕ. Ƒàļļš ƃàçķ ţö ļéñĝţĥ-ƃàšéđ þŕé-ƒîļţéŕîñĝ. ▒

▒ Çĥàŕàçţéŕ-ļéṽéļ Ļéṽéñšĥţéîñ šçöŕîñĝ (öñ `[]ŕüñé`) îš àþþļîéđ ţö ~200 ţŕîĝŕàḿ çàñđîđàţéš. Ţĥîš îš çöŕŕéçţ ƒöŕ àļļ šçŕîþţš îñçļüđîñĝ ÇĴĶ (éàçĥ çĥàŕàçţéŕ îš à ḿöŕþĥéḿé). ▒

▒ ÜÎ šéàŕçĥ üšéš ŕàñķéđ ƒüļļ-ţéẋţ šéàŕçĥ: ▒

- ▒ **ŠǪĻîţé**: ƑŢŠ5 `ţŕîĝŕàḿ` ţöķéñîžéŕ ƒöŕ šüƃšţŕîñĝ ḿàţçĥîñĝ öñ ţéŕḿ ţéẋţ. ▒
- ▒ **ÞöšţĝŕéŠǪĻ**: þĝ_ţŕĝḿ `šîḿîļàŕîţý()` ŕàñķîñĝ öñ `ţéẋţ_ļöŵéŕ`. ▒

▒ Ţéẋţ ñöŕḿàļîžàţîöñ àþþļîéš Üñîçöđé ÑƑÇ (`ĝöļàñĝ.öŕĝ/ẋ/ţéẋţ/üñîçöđé/ñöŕḿ`) ṽîà `ÑöŕḿàļîžéŢéŕḿ()` ƃéƒöŕé çöḿþàŕîšöñ, ĥàñđļîñĝ Àŕàƃîç đîàçŕîţîçš, Ĥàñĝüļ ĵàḿö çöḿþöšîţîöñ, àñđ àççéñţéđ Ļàţîñ çĥàŕàçţéŕš. ▒

## ▒ Þîþéļîñé Ţööļš ▒

▒ Ţŵö þîþéļîñé ţööļš îñţéĝŕàţé ţéŕḿîñöļöĝý îñţö ţĥé šţŕéàḿîñĝ þîþéļîñé ([É-03](/contribute/architecture/engine/e-03-tool-system)): ▒

▒ **`ţéŕḿ-ļööķüþ`** (Éñŕîçĥ) -- Šçàñš šöüŕçé ţéẋţ ƒöŕ ķñöŵñ ţéŕḿš, àţţàçĥéš `ŢéŕḿÀññöţàţîöñ` ŵîţĥ `ŢéẋţŔàñĝé` çĥàŕàçţéŕ þöšîţîöñš. Đöŵñšţŕéàḿ ţööļš (ÀÎ ţŕàñšļàţé, ǪÀ) üšé ţĥéšé àññöţàţîöñš ƒöŕ çöñţéẋţ. ▒

▒ **`ţéŕḿ-éñƒöŕçé`** (Ṽàļîđàţé) -- Çĥéçķš þŕéƒéŕŕéđ ţéŕḿ üšàĝé îñ ţàŕĝéţ ţéẋţ. Ŕéþöŕţš ƒöŕƃîđđéñ ţéŕḿš, ñöñ-þŕéƒéŕŕéđ ṽàŕîàñţš, đéþŕéçàţéđ ţéŕḿš, àñđ ḿîššîñĝ ţàŕĝéţ çöüñţéŕþàŕţš. ▒

▒ Ŕéļàţéđ ÀÎ àñđ ŕéđàçţîöñ ţööļš (ŕéĝîšţéŕéđ îñ `çöŕé/àî/ţööļš/` àñđ
`çöŕé/ţööļš/`): ▒

▒ **`ţéŕḿ-éẋţŕàçţ`** (Éñŕîçĥ, ÀÎ) -- ĻĻḾ éẋţŕàçţîöñ öƒ çàñđîđàţé ţéŕḿš. Üšéš àñ ÀÎ þŕöṽîđéŕ ƒŕöḿ [É-07](/contribute/architecture/engine/e-07-model-providers). ▒

▒ **`éñţîţý-éẋţŕàçţ`** (Éñŕîçĥ, ÀÎ) -- Ñàḿéđ éñţîţý àññöţàţîöñ (þéöþļé, öŕĝàñîžàţîöñš, þŕöđüçţš, đàţéš, ļöçàţîöñš). Šéŕṽéš ḿüļţîþļé þüŕþöšéš: çöñţéñţ-ḿéḿöŕý ĝéñéŕàļîžàţîöñ ([Ç-09](/contribute/architecture/context/c-09-content-memory)), đö-ñöţ-ţŕàñšļàţé ḿàŕķéŕš, ţŕàñšļàţîöñ ĥîñţš, àñđ ţéŕḿîñöļöĝý çàñđîđàţé đîšçöṽéŕý. Šĥöüļđ ŕüñ éàŕļý îñ ţĥé þîþéļîñé -- ƃéƒöŕé `ŕéçýçļé`. ▒

▒ **`ŕéđàçţ`** (Ţŕàñšƒöŕḿ) -- Þŕîṽàçý ţööļ ŕéþļàçîñĝ éñţîţý ṽàļüéš ŵîţĥ ţýþéđ þļàçéĥöļđéŕš (é.ĝ., "Ĵöĥñ" -> `\{PERSON\}`) ƃéƒöŕé éẋţéŕñàļ šéŕṽîçéš. Šéé [Ç-10](/contribute/architecture/context/c-10-redaction). ▒

▒ **`üñŕéđàçţ`** (Ţŕàñšƒöŕḿ) -- Ŕéšţöŕéš öŕîĝîñàļ éñţîţý ṽàļüéš àƒţéŕ éẋţéŕñàļ þŕöçéššîñĝ. Þàîŕéđ ŵîţĥ `ŕéđàçţ`:
`ŕéàđéŕ -> éñţîţý-éẋţŕàçţ -> ŕéđàçţ -> [éẋţéŕñàļ ḾŢ] -> üñŕéđàçţ -> ŵŕîţéŕ` ▒

## ▒ Çöñçéþţ ŕéļàţîöñš ▒

▒ Çöñçéþţš àŕé ļîñķéđ ƃý þéŕšîšţéđ, ţýþéđ, đîŕéçţéđ éđĝéš. À `ÇöñçéþţŔéļàţîöñ`
